At inference, TabPFN v2 runs a small ensemble. Each member sees the same data with a different feature order, a different permutation of class labels, and a different preprocessing choice, for example quantile transform, power transform, added SVD features or one-hot encoding. Four members for classification, eight for regression. Outputs are averaged with softmax temperature 0.9. Limits: 10 thousand rows, 500 features, 10 classes. Memory grows with the number of cells, under a kilobyte each. Headline result from the paper: in 2.8 seconds, default TabPFN beat an ensemble of baselines tuned for four hours.
